# Управление складом - Текстиль Плюс

Учебный проект для управления складом и снабжением швейного производства.

## Описание

Прототип модуля управления складом с функциями:
- Учет материалов
- Регистрация прихода материалов
- Списание материалов по методам FIFO и LIFO
- Отчеты по остаткам

## Требования

- Python 3.7+
- MySQL 5.7+ или MySQL 8.0+
- Установленная база данных MySQL

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте базу данных в MySQL:
```sql
CREATE DATABASE textile_warehouse CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. Настройте параметры подключения в файле `db.py`:
```python
DB_CONFIG = {
    'host': 'localhost',
    'database': 'textile_warehouse',
    'user': 'root',  # Ваш пользователь MySQL
    'password': 'root'  # Ваш пароль MySQL
}
```

4. Инициализируйте базу данных (создаст таблицы и заполнит тестовыми данными):
```bash
python db.py
```

При первом запуске база данных автоматически заполнится тестовыми данными:
- Материалы: Хлопок, Лен, Фурнитура, Подкладка
- Партии материалов с разными датами для тестирования FIFO/LIFO
- Примеры операций прихода и списания

## Запуск приложения

```bash
python ui_main.py
```

## Структура проекта

- `db.py` - подключение к MySQL, создание таблиц и заполнение тестовыми данными
- `models.py` - функции для работы с БД (добавление, изменение, удаление материалов, приход, списание, остатки)
- `fifo_lifo.py` - логика выбора партий по FIFO и LIFO
- `config.py` - настройки стилей приложения (цвета, шрифты, размеры)
- `utils.py` - вспомогательные классы (ScrollableFrame для прокрутки)
- `ui_main.py` - главное окно приложения с менеджером экранов и полноэкранным режимом
- `ui_materials.py` - экран управления материалами (Frame)
- `ui_receipt.py` - экран регистрации прихода (Frame)
- `ui_issue.py` - экран списания материалов (Frame)
- `ui_reports.py` - экран отчета по остаткам (Frame)

## Структура базы данных

### Таблица `materials`
- `id` - первичный ключ
- `name` - название материала
- `unit` - единица измерения

### Таблица `batches`
- `id` - первичный ключ
- `material_id` - внешний ключ на materials
- `quantity` - количество
- `price` - цена за единицу
- `received_at` - дата и время поступления

### Таблица `movements`
- `id` - первичный ключ
- `material_id` - внешний ключ на materials
- `movement_type` - тип операции ('IN' или 'OUT')
- `batch_id` - внешний ключ на batches (NULL для некоторых операций)
- `quantity` - количество
- `created_at` - дата и время операции

## Использование

1. **Полноэкранный режим**: 
   - Нажмите `F11` для переключения полноэкранного режима
   - Нажмите `Esc` для выхода из полноэкранного режима

2. **Добавление материалов**: Откройте "Материалы" и добавьте новый материал с указанием названия и единицы измерения.

3. **Редактирование материалов**: Выберите материал в таблице, измените данные и нажмите "Изменить".

4. **Удаление материалов**: Выберите материал в таблице и нажмите "Удалить" (удалит также все связанные партии и операции).

5. **Регистрация прихода**: Откройте "Приход материалов", выберите материал, укажите количество и цену. Текущий остаток отображается автоматически.

6. **Списание материалов**: Откройте "Списание материалов", выберите материал, укажите количество и метод списания (FIFO или LIFO).

7. **Просмотр остатков**: Откройте "Отчет по остаткам" для просмотра текущих остатков всех материалов.

## Методы списания

- **FIFO (First In, First Out)**: Старые партии списываются первыми
- **LIFO (Last In, First Out)**: Новые партии списываются первыми
